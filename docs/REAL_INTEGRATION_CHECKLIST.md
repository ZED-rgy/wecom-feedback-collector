# 真实企微接入清单

请按下面清单准备信息。Secret、私钥、Webhook Token 不要直接发在聊天里，建议只放在运行 Windows 机器的 `.env` 或指定私钥文件中。

## 1. Windows 企微账号接收（当前方案）

- [ ] 这台电脑已登录目标企微员工账号；
- [ ] 企微桌面端保持登录；群窗口不需要前台可见；
- [ ] 目标群名称和备注已填写，名称尽量唯一；
- [ ] 目标员工显示名称已填写（当前为“冉光意”）；
- [ ] 已安装 Windows 依赖：`python -m pip install -e ".[windows]"`；
- [ ] 先运行 `python -m wecom_feedback diagnose-local`，确认进程、密钥、目标群均通过；
- [ ] 再运行 `python -m wecom_feedback run-local --once` 做一次真实读取；
- [ ] 最后运行 `python -m wecom_feedback run-local`，或在控制台启用本地数据库接收；
- [ ] OCR/UI 模式仅作为回退：`python -m wecom_feedback run-ui`。

## 2. Windows 企微发送账号（必需）

- [ ] 这台电脑已登录目标企微员工账号；
- [ ] 企业微信版本号；
- [ ] Windows 屏幕分辨率和缩放比例；
- [ ] 企业微信安装路径；
- [ ] 是否允许电脑保持登录、解锁并长期运行；
- [ ] 发送前是否先采用“人工确认”模式；
- [ ] 群名称/群备注是否唯一，作为发送前二次校验条件。

## 3. 企微机器人/智能表格（官方 CLI 通道）

- [ ] 安装 `npm install -g @wecom/cli`；
- [ ] 在本机完成一次 `wecom-cli auth init`，并用 `wecom-cli auth show` 确认已授权；
- [ ] 目标智能表格由该机器人创建或拥有；
- [ ] 控制台填写智能表格链接、Bot ID、Bot Secret；接口地址可留空；
- [ ] 首次测试保持 `dry-run=true`，确认字段映射后再关闭；
- [ ] 程序使用 CLI 读取结构、写入新反馈记录，不改写参考表。

## 4. 业务规则

- [ ] 只处理一个客户群，还是后续支持多个群；
- [ ] 摘要发送时间和时区（默认 Asia/Shanghai）；
- [ ] 是否只收集 @目标账号 的消息；
- [ ] 是否把连续 90 秒内的多条消息合并为一条反馈；
- [ ] 反馈分类和优先级规则；
- [ ] 历史消息需要回溯多久。

## 建议的安全提供方式

可以先提供非敏感信息：Windows/企微版本、安装路径、群名称、群备注、员工 UserID、SDK 文件名和位数。Secret、私钥、Token 只需在目标机器本地配置，不需要粘贴到对话中。
